# 回答類型庫 v0.1

分類對象是本次回答，參考問題與取得的新聞片段；不是文章主題或圖表類型。主要類型一個，次類型不重複、不含主要類型；選擇確實支撐回答的類型即可。

| ID | 類型／閱讀任務 | 必須保留 | 常見邊界 |
| --- | --- | --- | --- |
| event_brief | 事件事實敘述：發生什麼？ | 人、事、時、地、相關對象、已知結果 | 預設文字；不是所有欄位都已知，不補造原因 |
| human_story | 人物與經驗敘事：處境與選擇？ | 背景、經歷、原話與限制 | 預設文字與引文，不把個人經驗當全體統計 |
| event_context | 事件脈絡與重建：如何走到這裡？ | 關鍵事件、時間、參與者、轉折與疑點 | 有先後不代表有因果 |
| issue_explainer | 議題與機制解釋：是什麼、如何運作？ | 概念、背景、機制、範圍與例外 | 不因來源有圖就要求製圖 |
| positions_debate | 立場與爭點分析：分歧在哪裡？ | 發言者、主張、理由、證據與共同點 | 不強分正反兩方，不製造虛假平衡 |
| data_analysis | 資料現況與趨勢：規模與差異？ | 指標、單位、期間、分母、方法與限制 | 數據為核心問題才作主類型 |
| comparative_analysis | 對象與方案比較：同異及意義？ | 對象、共同維度、基準、不可比之處 | 不強行量化質性差異 |
| accountability | 調查揭露與問責：落差及責任？ | 問題、證據、權責、當事方回應、未解處 | 缺少回應要揭露，不補寫回應 |
| discourse_analysis | 輿論與媒體敘事：如何談論？ | 文本來源、樣本、群體、主題、方法 | 不從文本樣本推全體支持比例 |
| impact_scenarios | 影響、風險與情境：對誰、什麼條件？ | 受影響者、途徑、期間、假設、不確定性 | 區分已發生影響與未來情境 |
| policy_evaluation | 政策執行與成效：承諾做到嗎？ | 目標、措施、投入、進度、成果、評估限制 | 目標不等於預測；前後差異不等於政策效果 |
| service_guidance | 服務資訊與行動：適用嗎、怎麼做？ | 資格、步驟、期限、窗口、例外、資訊日期 | 歷史資料不能當今日有效規則 |
| claim_verification | 說法查證與證據釐清：支持程度？ | 說法、提出者、脈絡、支持／反對證據、判定範圍 | 不強迫真假二分；假訊息研究不自動屬於查核 |

以主要閱讀任務判斷重疊：檢驗承諾與結果以 policy_evaluation 為主；追查責任與異常以 accountability 為主；當事人遭遇若只是背景，human_story 不必成為次類型。

例如，只問「何時宣布停辦」用 event_brief；問「制度為何保護不了師生」可能用 issue_explainer + accountability。來源是調查專題，也不改變前者的簡答任務。

另用 tags 保留四個獨立軸：topic（教育、交通）、method（訪談、文件比對、統計）、angle（權利保障、空間差異）、temporal（歷史回顧、事件當時、未來情境）。這些不增加主要類型。
